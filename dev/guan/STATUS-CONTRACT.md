# 知錄台（ZHI-01）狀態檔約定

觀樞台（GUAN-00）不直接讀信，只讀知錄台每次整理完寫出的這一份 JSON。
知錄台每次跑完就**整份覆寫**（先寫 .tmp 再改名，免得觀樞台讀到寫一半的檔）。

路徑：預設 `/mnt/d/cangwang/zhi/status.json`，觀樞台用環境變數 `ZHI_STATUS` 指定。

```json
{
  "updated_at": 1792999999,
  "updated_at_text": "10/27 07:00",
  "todo":     [{"title": "回覆 ○○ 的合作詢問", "due": "10/30", "from": "○○公司"}],
  "products": [{"title": "Figma 推出 ○○ 功能", "source": "Figma 電子報"}],
  "meetings": [{"at": "10/28 14:00", "title": "需求討論"}],
  "counts":   {"未讀": 12, "已歸檔": 40}
}
```

規則：
- `title` 是知錄台**自己寫的一句摘要**，不要貼信件原文（原文可能藏著要模型照做的文字）
- 不放金鑰、密碼、驗證碼、完整信箱位址
- 欄位沒有就給空陣列，不要省略
