# 搜尋舊卦＋保存期限契約（0087）

卦會被清，而清不清看兩件事：**牒**與**這一卦有沒有被保護**。搜尋頁要把這件事講清楚，
並在該引導的地方引導持牒。後端這一側已補齊，這份是給前端（`CangWang-web`）的契約。

---

## 一、規則（前端照這個寫文案，不要自己另訂數字——數字一律從 API 拿）

| | 保存期限（從起卦算） |
| --- | --- |
| 無牒 | 90 天 |
| 觀微 | 180 天 |
| 知幾 | 365 天 |
| 藏往 | 永久 |
| 日運卦 | 一律 7 天（不分方案、不受保護、不進搜尋） |

**不論方案都永久保留**：留過印證（準／部分準／不準）、收進心跡、被心事的留言引用。

**斷牒緩衝**：牒到期後 30 天內，保存期限仍照原方案；過了才回到 90 天。
清理每天 03:00 UTC（台灣 11:00）跑一次。

## 二、`mode: "cast_search"`

```jsonc
// 請求
{ "mode": "cast_search", "q": "工作 升遷", "before": null, "limit": 30 }
```

- `q`：空白分隔多個關鍵字，**全部都要中**。比對問句、摘要、追問的問句、本卦／變卦名。
  最多 5 個關鍵字、50 字。
- `before`：分頁游標，第一頁給 `null`，之後原樣帶回上一頁的 `nextBefore`。
- `limit`：1–50，預設 30。

```jsonc
// 回應
{
  "kind": "ok",
  "query": "工作 升遷",            // 後端整理過的字串（顯示「找『…』」用）
  "casts": [{
    "id": "…", "question": "…", "digest": "…", "gua_ben": "乾為天", "gua_bian": null,
    "category": "事業", "character_id": "…", "created_at": "…", "due_date": null,
    "thread_id": null, "verdict": 1,
    "kept": true,                   // 永久保存（受保護或藏往）
    "expiresAt": null,              // 預計清理時點；kept 時為 null
    "daysLeft": null                // 剩幾天（向下取整）；kept 時為 null
  }],
  "nextBefore": "2026-07-01T…",     // null＝沒有下一頁
  "keep": {
    "days": 90,                     // 此人此刻的保存天數；null＝永久
    "graceUntil": null,             // 斷牒緩衝截止；不在緩衝期為 null
    "freeDays": 90
  }
}
// 失敗：{ "kind": "err", "msg": "要找什麼？打個字。" }
```

**搜尋只找得到還沒被清掉的卦。** 90 天前已被清掉的，就是找不到——這正是提醒要說的事。

## 三、其他地方多帶的欄位

- `profile`：`castKeepDays`（null＝永久）、`castKeepGraceUntil`
- `plan_list`：每個方案多 `keep_days`；外層多 `keep: { days, graceUntil, freeDays, fortuneDays }`
  ——方案頁的比較表加一列「卦保存」。

## 四、畫面建議

### 每一筆結果的標籤

| 狀態 | 標籤 |
| --- | --- |
| `kept` | `永久` |
| `daysLeft > 14` | `剩 N 天`（淡色） |
| `daysLeft <= 14` | `剩 N 天`（警示色）＋旁邊一顆「印證」或「收進心跡」的捷徑 |

快到期的那一筆旁邊直接給「怎麼留住」的動作，比頂端一條警告有用：人是在看到「這一卦
要沒了」的時候才會想留。

### 搜尋框下方的固定一行（依 `keep` 切換）

| 條件 | 文案 |
| --- | --- |
| `days === 90`（無牒） | 卦留 90 天。印證過、收進心跡的永久保存。持牒可延至一年，藏往永不清理。〔看玉牒〕 |
| `days` 為 180／365 | 卦留 {days} 天。印證過、收進心跡的永久保存。藏往永不清理。〔看玉牒〕 |
| `days === null` 且無 `graceUntil` | 藏往：卦永久收藏。 |
| `graceUntil` 有值 | 玉牒已到期。{graceUntil 的日期} 前續牒，舊卦照原規格保留；之後只留最近 90 天。〔續牒〕 |

`graceUntil` 那一行是最該顯眼的：那是持牒者最可能流失、也最可能回頭的時候，
而且「一年份的卦要沒了」是真的會發生的事，不是話術。

### 搜尋沒有結果時

> 找不到「{query}」。超過 {days} 天、沒有印證也沒收進心跡的卦已經清掉了。

（藏往不顯示後半句。）
