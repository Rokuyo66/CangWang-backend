# 起卦標價契約（前端已接：`CangWang-web` `claude/paid-divination-display-22lpre`）

排盤頁那顆「入觀解卦」目前不標價。已登入、當日免費卦已用盡的人按下去，會直接被扣
10 靈石——扣款本身是對的（`billCast` 一直都在跑），錯的是按之前沒人告訴他要扣。
TG 那邊的按鈕從第一天就寫著「免費剩 N 卦／耗 10 靈石」，網頁這邊沒有。

後端這一側已補齊，這份是給前端（`CangWang-web`）的契約。

---

## 一、按鈕該怎麼標

**未登入**：不標價，也不必問後端。網頁排盤是純本機的，`interpret` 根本不受理無 JWT
的請求（沒有 `Authorization` 又沒有內部金鑰一律 403）。這顆鈕按下去該做的是引導登入，
標價等登入後再說——這與現況一致，不用改。

**已登入**：`profile` 回傳裡有三個欄位，照它標：

| 欄位 | 意思 |
| --- | --- |
| `castFreeLeft` | 今日還剩幾卦免費（已依方案分級、台北日界） |
| `castFreePerDay` | 這個方案每日幾卦免費（顯示「N/M」用，非必要） |
| `castCost` | 額度用盡後，每卦扣幾顆靈石（目前 10） |

- `castFreeLeft > 0` → `入觀解卦（免費剩 N 卦）`
- `castFreeLeft === 0` 且 `lingshi >= castCost` → `入觀解卦（${castCost} 靈石）`
- `castFreeLeft === 0` 且 `lingshi < castCost` → 仍可按，但先提示靈石不足（後端也會擋，
  見下面的 `paywall`）

## 二、起卦之後不必重打 profile

起卦成功的回應多了兩個欄位，按完當場就能把按鈕改標，省一次往返：

```jsonc
{ "kind": "ok", "castId": "…", "chart": {…}, "reading": "…",
  "paid": 0,        // 這一卦實際扣了幾顆（吃免費額度時為 0）
  "freeLeft": 1,    // 扣完這一卦之後，今日還剩幾卦免費
  "castCost": 10 }  // 額度外每卦的價，同 profile.castCost
```

`paid > 0` 時該給一句「額度外加卦，靈石 −10」的回饋——TG 有，網頁也該有，
不然靈石默默少了十顆，人只會以為是 bug。

## 三、擋下來時有數字可講

額度用盡又扣不動靈石，回的是：

```jsonc
{ "kind": "paywall", "need": 10, "lingshi": 3, "freeLeft": 0 }
```

`need` 是這一卦要幾顆、`lingshi` 是他現在有幾顆。訊息請把兩個數字都講出來
（「加卦需 10 顆，你有 3 顆」），別只丟一句「靈石不足」讓人自己去錢包頁數。

## 四、`quota_key` 已經不看了

起卦 body 以前可以帶 `quota_key`，帶了就用它當額度鍵。登入路徑現在一律以 JWT 解出的
帳號記帳，前端傳什麼都無效（`user_id` 早就是這條鐵則，額度鍵補上同一條）。
這欄位只剩內部金鑰路徑在用（TG 記在 `tg:<id>` 上）。

前端如果還在送 `quota_key`，可以直接拿掉——留著不會壞，但它不再有任何作用。

## 五、前端接法（2026-08-24 已實作）

`CangWang-web` 那側照這份契約接完了，接的位置與這份文件原本的建議略有出入，記在這裡：

- **標價主位改在「請誰為你解卦」的三位角色底下**，不是按鈕上。按鈕在排盤頁、離扣款
  還隔一次選人，選人卡才是「按下去就會扣」的最後一關，話擺在那裡最不會被略過。
  按鈕仍標短版（`入觀解卦（免費剩 N 卦）`／`入觀解卦（💎N）`），只是不當唯一出口。
- 三種文案分別是：`此卦免費 · 今日尚餘 N / M 卦`、`今日免費卦已用盡 · 此卦將耗 💎N`、
  `今日免費卦已用盡 · 此卦需 💎N，你有 💎M`。
- `paywall` 已改成把 `need` 與 `lingshi` 兩個數字都講出來。
- `paid > 0` 時批文末尾補一句「此卦為額度外加卦，靈石 −N」。
- 三個欄位任一沒帶（線上函式還是舊版）就整塊省略，維持原本不標價的樣子——
  寧可不標，也不要標一個跟實際扣款打架的數字。

**這一切的前提是 `interpret` 已部署到線上。** 欄位是 8/23 那支 commit 才加的，
Supabase 的函式不隨 git 自動更新（見 `dev/deploy-howto.md` 第 2 步）。線上若還是舊版，
profile 不會有這三個欄位，前端就會照上面最後一條靜靜地不標價——畫面看起來與改版前一樣。
