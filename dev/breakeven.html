上線後實測「用掉額度」

-- 近 30 天，每位有用 AI 的人平均花多少（NT$），依方案分
select coalesce(p.plan,'free') as 方案,
       count(distinct c.user_id) as 人數,
       round(sum(c.usd) * 32 / count(distinct c.user_id), 2) as 每人每月NT
from ai_usage_cost c
left join profiles p on p.id = c.user_id
where c.created_at >= now() - interval '30 days' and c.user_id is not null
group by 1 order by 1;
把「每人每月NT」除以上表的用滿成本，就是真的用掉額度 %。
